# Vendor Handshake - Vendor Onboarding Platform (VOB)

Public, internet-facing Laravel 12 app. Vendors sign in from an emailed link, fill the Terms of Trade form, upload documents to S3,
verify their bank account with Cashfree and submit. There is **no business database**: all data goes through the Admin Panel REST API
(`docs/API_CONTRACT.md`). Plan and phases: `docs/DEVELOPMENT_PLAN.md`. Working rules: `CLAUDE.md`.

## Status

Phase 1 (scaffolding, `AdminApiClient`, logging + purge, layout with status tracker, tests). Phase 2 (login/password flow) not started.

## Setup

```
composer install
cp .env.example .env
php artisan key:generate        # owner runs this
php artisan migrate             # sessions, cache, jobs, api_logs (SQLite by default; set DB_* for MySQL)
vendor/bin/pest                 # needs a .env to exist, otherwise PHPUnit reports every test as a warning
```

## Keys and secrets (owner-created, never committed, never generated by the code)

| Variable | Meaning |
|---|---|
| `ADMIN_API_BASE_URL` | Admin API base incl. prefix, e.g. `https://admin.internal/api/v1` (its path is the signed path) |
| `ADMIN_API_HMAC_SECRET` | same value as `API_HMAC_SECRET` on the Admin side |
| `ADMIN_API_RSA_PUBLIC_KEY_PATH` | `vob_public.pem`, default `storage/app/keys/vob_public.pem` (`*.pem` is git-ignored) |
| `ADMIN_API_RSA_KEY_ID` | key id, e.g. `k1` |
| `ADMIN_API_TIMEOUT`, `ADMIN_API_RETRIES` | seconds / extra attempts for GET, PUT, DELETE (POST is never retried) |
| `API_LOG_RETENTION_MONTHS` | `api_logs` retention, default 2 |
| `VOB_ENFORCE_REQUIRED`, `VOB_ENFORCE_DOCUMENTS` | `false` = Submit not blocked on mandatory fields / documents. Ignored (always on) in production |
| `VOB_DISPLAY_TIMEZONE` | timezone for "Draft saved ..." (default `Asia/Kolkata`) |

A missing key/secret/URL raises a clear "not configured" error before any request is sent.

## Scheduler

`logs:purge-api --months=2` runs daily (`routes/console.php`). Cron entry:

```
* * * * * cd /path/to/vob && php artisan schedule:run >> /dev/null 2>&1
```

## Layout

- `app/Services/AdminApi/AdminApiClient.php` - the only gateway to the Admin API: HMAC headers on every call, `X-Auth-Data`
  envelope (AES-256-GCM + RSA-OAEP) with a random decoy body for login / password change, Bearer token from the server-side session,
  retries for idempotent calls (re-signed each attempt), 401 on a Bearer call ends the session.
- `RequestSigner`, `CredentialEnvelope`, `AdminSession` (token + user in the Laravel session only), `ApiLogger`, `ApiLogRedactor`.
- `api_logs` - every outbound attempt; passwords, tokens, emails, `X-Auth-Data`, signatures redacted, account / PAN / GST numbers masked.
- `resources/views/layouts/app.blade.php` + `components/status-tracker.blade.php` - left-margin tracker rendered from the API `progress`.
- `App\Support\EnforcementSwitches` - the two development switches; the layout shows a "Development mode" banner when one is off.
